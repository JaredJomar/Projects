# Apple TV Enhancements

Automate common Apple TV playback actions, including skipping segments, starting the next episode, and entering fullscreen.

## Features

### 🎬 Playback Automation
- Automatically skips recaps and intros when available
- Starts the next episode when the next-episode control appears
- Can automatically enter fullscreen
- Rechecks the player for available playback actions

### ⚙️ Playback Settings
- Toggle recap skipping, intro skipping, next episode, and fullscreen separately
- Open or close the settings dialog with F2
- Save preferences through the settings dialog or Tampermonkey menu
- Settings are enabled by default

## Keyboard Controls

| Key | Function |
| --- | --- |
| `F2` | Open or close settings |
| `Escape` | Exit fullscreen |

## Settings

The settings dialog lets you enable or disable recap skipping, intro skipping, next-episode playback, and automatic fullscreen. Each option is enabled by default.
