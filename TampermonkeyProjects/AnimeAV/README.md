# AnimeAV Auto Server Selector

Improve your AnimeAV viewing experience with automatic language and video-server selection.

## Features

### 🎦 Video Selection
- Automatically selects your preferred language
- Selects your preferred video server
- Remembers your choices across sessions
- Supports dynamically loaded playback options

### 🎬 Playback Automation
- Applies your saved choices when the page is ready
- Updates selection when new options become available
- Avoids repeated selections
- Works with AnimeAV video pages

### ⚙️ Smart Settings
- F2 hotkey for quick access
- Separate language and server preferences
- Persistent settings
- Escape key and outside-click closing

## Keyboard Controls

| Key | Function |
|-----|----------|
| F2 | Open/close settings |
| Escape | Close settings |

## Settings

Access the settings panel with F2 to customize:
- Audio and subtitle language
- Preferred video server
- Automatic selection preferences
