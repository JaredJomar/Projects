# JKAnime Auto Server Selector

Enhance your JKAnime experience with automatic server selection and player-prompt handling.

## Features

### 🎦 Server Selection
- Automatically selects your preferred server
- Remembers your preference across sessions
- Supports dynamically loaded server controls

### 🎬 Player Automation
- Automatically accepts the player prompt
- Runs inside the JKAnime player iframe
- Prevents repeated clicks on handled buttons

### ⚙️ Smart Settings
- F2 hotkey for quick access
- Validated server preferences
- Persistent preferences
- Escape key and outside-click closing

## Keyboard Controls

| Key | Function |
|-----|----------|
| F2 | Open/close settings |
| Escape | Close settings |

## Settings

Access the settings panel with F2 to customize:
- Preferred video server
- Automatic selection preferences
- Settings persistence
