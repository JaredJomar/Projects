# AniList Send to TV Time

Add a TV Time button to AniList anime pages and carry the title into a TV Time search.

## Features

### 🎯 AniList to TV Time
- Adds a TV Time button to AniList anime pages
- Copies the anime title when the button is used
- Stores the title for use on TV Time
- Opens the TV Time media search page

### 🔍 Search Assistance
- Fills the TV Time search with the AniList title
- Retries when the search interface loads late
- Supports TV Time search pages reached through the title button

### 🔄 Dynamic Page Support
- Watches for AniList content changes before adding the button
- Reinitializes after single-page app navigation
- Observes TV Time pages while waiting for the search field
