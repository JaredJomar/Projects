# ChatGPT Delete Chat Shortcut

Map the Delete key to ChatGPT's Ctrl+Shift+Delete chat deletion shortcut when you're not using an editing control.

## Features

### ⌨️ Delete Shortcut
- Maps an unmodified Delete key press to Ctrl+Shift+Delete
- Ignores Delete presses with modifier keys already held
- Leaves Delete behavior unchanged in text inputs and editing controls

### 🔄 Page Navigation Support
- Reattaches the shortcut after ChatGPT single-page navigation
- Initializes the listener when the page is ready

## Keyboard Controls

| Key | Function |
| --- | --- |
| `Delete` | Trigger ChatGPT's Ctrl+Shift+Delete chat shortcut outside editing controls |
