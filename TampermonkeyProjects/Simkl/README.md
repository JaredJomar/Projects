# Media Tracker Sender

Add media-tracker buttons to Plex, Simkl, AniList, and supported streaming pages to quickly search or send a title to another service.

## Features

### 🎯 Tracker Shortcuts
- Adds Simkl, AniList, and TMDB buttons to Plex
- Adds AniList, TMDB, Peliplus, SoloLatino, and LaMovie buttons to supported title pages
- Copies the current title when a button is used
- Opens the matching service or search page

### 🖥️ Floating Panels
- Shows a floating panel on Peliplus, SoloLatino, and LaMovie title pages
- Provides quick access to Simkl, AniList, TMDB, and LaMovie
- Displays service labels when hovering over panel buttons

### 🔄 Dynamic Page Support
- Watches for page content changes before adding buttons
- Responds to navigation within supported single-page apps
- Removes the floating panel when leaving a supported title page

## Version History
